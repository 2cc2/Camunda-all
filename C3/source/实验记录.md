# 发送的json
## 实验步骤
1. 启动c8.exe
2. 启动camunda
3. camunda部署一个实例，此时可以在operate上看到一个卡住的进程
4. 启动index.ts 指令npx ts-node index.ts
5. postman发送transport下面列出的三条json文件(使用sendMsg.ts后可以新开一个终端执行文件代替这些)
6. 可以观察到operate上进程继续进行

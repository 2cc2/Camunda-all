# 如何运行本项目

## 确保本机安装了docker并且启动

## 启动 RabbitMQ：
docker run -d --name rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:3-management
命令会自己下载安装RabbitMQ


## 启动 Camunda 8（你的 c8.exe）
## 部署 BPMN：部署 Transport.bpmn 和 Freight-Forward.bpmn

## 启动 Workers + Bridge：
cd nodejs && npx ts-node source/index.ts

## 发送消息（另一个终端）：
### Transport 流程
npx ts-node source/sendMsg.ts
### FF 流程
npx ts-node source/sendFFMsg.ts
